📦 GitHub Pages 部署說明

本專案採用純前端單一檔案架構（index.html），可免費託管於 GitHub Pages 並在手機上當作原生 App 使用：

  1. 在 GitHub 建立新的 Repository（例如 good-land-planner）。
  2. 將本程式碼儲存為 index.html 並上傳至該 Repository。
  3. 進入 Repository 的 Settings → Pages。
  4. 在 Source 選擇 main 分支並儲存即可！
